2Alternative: Slots für Google Forms oder Microsoft Forms

Im Formular eine Frage „Terminwunsch“ (Auswahl oder Dropdown) anlegen und die Zeilen als Optionen einfügen. Google Forms: Optionen einfügen mit Strg+V in das erste Optionsfeld. Microsoft Forms: „Optionen im Stapel einfügen“ im Menü der Frage.

2Online-Anmeldung über Google-Tabelle

Eltern kreuzen über einen Link alle Termine an, an denen sie können, und wählen auf Wunsch einen Lieblingstermin. Das Tool verteilt danach so, dass alle einen Termin haben, jeder Tag ein dichter Block ohne Lücken ist und möglichst viele Lieblingstermine passen. Nach der Freigabe sehen die Eltern ihren Termin über denselben Link.

Einmalige Einrichtung (ca. 10 Minuten)
  1. Auf sheets.new eine neue Google-Tabelle anlegen und z. B. „Elterngespräche 9b“ nennen.
  2. In der Tabelle oben Erweiterungen → Apps Script öffnen.
  3. Den vorhandenen Code im Editor löschen. Hier auf „Code kopieren“ klicken, im Editor einfügen und mit dem Disketten-Symbol speichern.
  4. Oben rechts Bereitstellen → Neue Bereitstellung. Beim Zahnrad Web-App wählen. „Ausführen als“: Ich. „Zugriff“: Jeder. Dann Bereitstellen.
  5. Google fragt nach Berechtigungen. Konto wählen, bei der Warnung auf Erweitert → Zu … wechseln (unsicher) und Zulassen. Die Warnung erscheint, weil das Skript von dir selbst stammt und nicht von Google geprüft ist.
  6. Die angezeigte Web-App-URL (endet auf /exec) kopieren und unten einfügen.

Fehlt bei „Zugriff“ die Option „Jeder“, erlaubt dein Schulkonto keine Links für Externe. Dann die Einrichtung mit einem privaten Google-Konto machen.
